# 🎮 Game Template Creator - Руководство

## 📖 О проекте
Это простая утилита на Python, которая автоматически создает структуру папок и файлов для новой игры. Программа демонстрирует использование древовидных структур данных на практике.

## 🚀 Как это работает

### Основная концепция
1. **Дерево как структура данных**:
   - Корневая папка игры — корень дерева
   - Папки (например, `assets/`, `src/`) — узлы дерева
   - Файлы (например, `index.html`) — листья дерева
   - Вложенные папки — потомки узлов

2. **Алгоритм работы**:
   ```python
   # 1. Получаем данные от пользователя
   # 2. Создаем корневую папку проекта
   # 3. Проходим по списку структуры (обход дерева)
   # 4. Для каждого элемента:
   #    - Если это папка (заканчивается на /) → создаем папку
   #    - Если это файл → создаем пустой файл
   ```

### Разбор кода по шагам

```python
import os  # Импортируем модуль для работы с файловой системой

# 1. Определяем структуру проекта как список
structure = ["index.html", "styles.css", "main.js", "assets/", "src/", "src/game.js"]
# Папки помечаются символом / в конце

# 2. Запрашиваем у пользователя данные
name = input("Название: ") or "Game"  # Если ввели пустую строку, будет "Game"
path = input("Путь: ") or "."         # "." означает текущую папку

# 3. Формируем полный путь к проекту
full = os.path.join(path, name)      # Правильно объединяем путь и имя
# Например: "D:\Projects" + "MyGame" = "D:\Projects\MyGame"

# 4. Создаем корневую папку проекта
os.makedirs(full, exist_ok=True)    # exist_ok=True означает "не ошибка, если уже существует"

# 5. ОБХОД ДЕРЕВА: создаем все элементы структуры
for item in structure:               # Проходим по каждому элементу списка
    p = os.path.join(full, item)     # Полный путь к текущему элементу
    
    if item.endswith('/'):           # Проверяем: это папка?
        os.makedirs(p, exist_ok=True)  # Создаем папку
    else:                            # Если это файл:
        os.makedirs(os.path.dirname(p), exist_ok=True)  # Создаем родительские папки
        open(p, 'w').close()         # Создаем пустой файл

print(f"Создано: {full}")            # Выводим результат
```

## 🛠 Как создать EXE-файл (программу)

### Способ 1: Использование PyInstaller (рекомендуется)

1. **Установите PyInstaller**:
   ```bash
   pip install pyinstaller
   ```

2. **Перейдите в папку с вашим скриптом**:
   ```bash
   cd путь_к_вашей_папке
   ```

3. **Создайте EXE-файл**:
   ```bash
   pyinstaller --onefile --name GameMaker game_template.py
   ```
   
   **Параметры**:
   - `--onefile` — все собрать в один EXE-файл
   - `--name GameMaker` — назвать программу "GameMaker"
   - `game_template.py` — имя вашего скрипта

4. **Найдите готовый файл**:
   - В папке `dist/` появится `GameMaker.exe`
   - Этот файл можно запускать на любом компьютере с Windows

### Способ 2: Упрощенный вариант (для новичков)

1. **Создайте файл `make_exe.bat`** (для Windows):
   ```batch
   @echo off
   pip install pyinstaller
   pyinstaller --onefile --name GameMaker main.py
   echo.
   echo Готово! EXE-файл находится в папке 'dist'
   pause
   ```

2. **Просто запустите этот bat-файл двойным кликом**

## 📁 Что создается после запуска

Если ввести название "MyGame" и путь "D:\Projects", будет создана структура:

```
D:\Projects\MyGame\
├── index.html          (пустой HTML-файл)
├── styles.css          (пустой CSS-файл)
├── main.js             (пустой JavaScript-файл)
├── assets\             (папка для ресурсов)
└── src\                (папка для исходного кода)

```

## 🔧 Частые проблемы и решения

### Проблема 1: "Permission denied"
**Решение**: Запустите программу от имени администратора или выберите другую папку.

### Проблема 2: "Файл не создается"
**Решение**: Проверьте, есть ли у вас права на запись в выбранную папку.

### Проблема 3: "PyInstaller не работает"
**Решение**:
1. Убедитесь, что Python установлен
2. Проверьте, что pip установлен: `pip --version`
3. Попробуйте: `python -m pip install pyinstaller`
