## Задача 1: Поиск дубликатов в списке
**Задача:** Напишите функцию, которая принимает список чисел и возвращает список дублирующихся элементов. Если дубликатов нет, верните пустой список.

**Диаграмма алгоритма:**
```
Начало → Получить список → Создать словарь для подсчёта → 
Для каждого элемента: увеличить счётчик → 
Отфильтровать элементы с счётчиком >1 → Вернуть список дубликатов
```

**Решение:**
```python
def find_duplicates(numbers):
    """
    Находит дубликаты в списке чисел
    """
    counter = {}
    
    # Подсчитываем количество каждого элемента
    for num in numbers:
        counter[num] = counter.get(num, 0) + 1
    
    # Возвращаем элементы, которые встречаются больше одного раза
    duplicates = [num for num, count in counter.items() if count > 1]
    return duplicates

# Пример использования:
print(find_duplicates([1, 2, 3, 2, 4, 5, 3]))  # [2, 3]
print(find_duplicates([1, 2, 3, 4, 5]))         # []
```

## Задача 2: Объединение двух списков без дубликатов
**Задача:** Создайте функцию, которая принимает два списка и возвращает новый список, содержащий все уникальные элементы из обоих списков.

**Диаграмма алгоритма:**
```
Начало → Получить список1 и список2 → 
Объединить оба списка → Преобразовать в множество → 
Преобразовать обратно в список → Вернуть результат
```

**Решение:**
```python
def merge_unique_lists(list1, list2):
    """
    Объединяет два списка, удаляя дубликаты
    """
    # Используем множество для удаления дубликатов
    unique_elements = set(list1 + list2)
    
    # Преобразуем множество обратно в список
    return list(unique_elements)

# Пример использования:
result = merge_unique_lists([1, 2, 3, 4], [3, 4, 5, 6])
print(result)  # [1, 2, 3, 4, 5, 6] (порядок может отличаться)
```

## Задача 3: Подсчёт частоты слов в тексте
**Задача:** Напишите программу, которая принимает строку текста и возвращает словарь, где ключи - слова, а значения - количество их появлений в тексте.

**Диаграмма алгоритма:**
```
Начало → Получить текст → Разделить на слова → 
Для каждого слова: увеличить счётчик в словаре → Вернуть словарь
```

**Решение:**
```python
def word_frequency(text):
    """
    Подсчитывает частоту слов в тексте
    """
    # Приводим текст к нижнему регистру и разбиваем на слова
    words = text.lower().split()
    
    frequency = {}
    
    for word in words:
        # Удаляем знаки препинания (базовый вариант)
        word = word.strip('.,!?;:')
        
        # Подсчитываем слова
        frequency[word] = frequency.get(word, 0) + 1
    
    return frequency

# Пример использования:
text = "Привет мир! Мир прекрасен, привет всем!"
print(word_frequency(text))
# {'привет': 2, 'мир': 2, 'прекрасен': 1, 'всем': 1}
```

## Задача 4: Поиск общих элементов в двух списках
**Задача:** Напишите функцию, которая находит общие элементы в двух списках и возвращает их в виде списка.

**Диаграмма алгоритма:**
```
Начало → Получить список1 и список2 → 
Преобразовать оба списка в множества → 
Найти пересечение множеств → 
Преобразовать в список → Вернуть результат
```

**Решение:**
```python
def find_common_elements(list1, list2):
    """
    Находит общие элементы в двух списках
    """
    # Преобразуем списки в множества и находим пересечение
    set1 = set(list1)
    set2 = set(list2)
    
    common = set1.intersection(set2)
    
    return list(common)

# Пример использования:
list_a = [1, 2, 3, 4, 5]
list_b = [4, 5, 6, 7, 8]
print(find_common_elements(list_a, list_b))  # [4, 5]
```

## Задача 5: Инвертирование словаря
**Задача:** Создайте функцию, которая принимает словарь и возвращает новый словарь, где ключи и значения поменялись местами. Если значения повторяются, сохраните последний ключ.

**Диаграмма алгоритма:**
```
Начало → Получить словарь → Создать пустой словарь → 
Для каждой пары ключ-значение: записать в новый словарь → 
Вернуть инвертированный словарь
```

**Решение:**
```python
def invert_dictionary(original_dict):
    """
    Меняет местами ключи и значения в словаре
    """
    inverted = {}
    
    for key, value in original_dict.items():
        # Меняем местами ключ и значение
        inverted[value] = key
    
    return inverted

# Пример использования:
original = {"яблоко": "apple", "банан": "banana", "вишня": "cherry"}
inverted = invert_dictionary(original)
print(inverted)  # {'apple': 'яблоко', 'banana': 'банан', 'cherry': 'вишня'}
```

## Задача 6: Удаление дубликатов с сохранением порядка
**Задача:** Напишите функцию, которая удаляет дубликаты из списка, сохраняя исходный порядок элементов.

**Диаграмма алгоритма:**
```
Начало → Получить список → Создать пустой список и множество → 
Для каждого элемента: если элемента нет в множестве, добавить → 
Вернуть список без дубликатов
```

**Решение:**
```python
def remove_duplicates_preserve_order(original_list):
    """
    Удаляет дубликаты, сохраняя порядок элементов
    """
    seen = set()
    unique_list = []
    
    for item in original_list:
        if item not in seen:
            seen.add(item)
            unique_list.append(item)
    
    return unique_list

# Пример использования:
numbers = [1, 2, 3, 2, 4, 3, 5, 1]
result = remove_duplicates_preserve_order(numbers)
print(result)  # [1, 2, 3, 4, 5]
```

## Задача 7: Поиск отсутствующих чисел
**Задача:** Дан список чисел от 1 до N, где одно число пропущено. Напишите функцию, которая находит пропущенное число.

**Диаграмма алгоритма:**
```
Начало → Получить список → Вычислить ожидаемую сумму (N*(N+1)/2) → 
Вычислить фактическую сумму → 
Вернуть разницу (пропущенное число)
```

**Решение:**
```python
def find_missing_number(numbers):
    """
    Находит пропущенное число в последовательности 1..N
    """
    if not numbers:
        return 1
    
    n = len(numbers) + 1  # +1 потому что одно число пропущено
    expected_sum = n * (n + 1) // 2
    actual_sum = sum(numbers)
    
    return expected_sum - actual_sum

# Пример использования:
sequence = [1, 2, 4, 5, 6]  # Пропущено 3
print(find_missing_number(sequence))  # 3
```

## Задача 8: Группировка слов по первой букве
**Задача:** Создайте функцию, которая принимает список слов и возвращает словарь, где ключи - первые буквы, а значения - списки слов, начинающихся на эту букву.

**Диаграмма алгоритма:**
```
Начало → Получить список слов → Создать пустой словарь → 
Для каждого слова: взять первую букву → 
Добавить слово в список по ключу-букве → Вернуть словарь
```

**Решение:**
```python
def group_words_by_first_letter(words):
    """
    Группирует слова по их первой букве
    """
    grouped = {}
    
    for word in words:
        # Берём первую букву слова (в нижнем регистре)
        first_letter = word[0].lower()
        
        # Если такой буквы ещё нет в словаре, создаём пустой список
        if first_letter not in grouped:
            grouped[first_letter] = []
        
        # Добавляем слово в список
        grouped[first_letter].append(word)
    
    return grouped

# Пример использования:
words_list = ["apple", "banana", "apricot", "cherry", "blueberry", "avocado"]
result = group_words_by_first_letter(words_list)
print(result)
# {'a': ['apple', 'apricot', 'avocado'], 'b': ['banana', 'blueberry'], 'c': ['cherry']}
```

## Задача 9: Поиск пар чисел с заданной суммой
**Задача:** Напишите функцию, которая в списке чисел находит все пары чисел, сумма которых равна заданному числу.

**Диаграмма алгоритма:**
```
Начало → Получить список и целевую сумму → Создать множество → 
Для каждого числа: вычислить complement = цель - число → 
Если complement есть в множестве: добавить пару → 
Добавить число в множество → Вернуть список пар
```

**Решение:**
```python
def find_pairs_with_sum(numbers, target_sum):
    """
    Находит все пары чисел, сумма которых равна target_sum
    """
    seen = set()
    pairs = []
    
    for num in numbers:
        complement = target_sum - num
        
        if complement in seen:
            # Добавляем пару (меньшее число сначала)
            pair = (min(num, complement), max(num, complement))
            if pair not in pairs:
                pairs.append(pair)
        
        seen.add(num)
    
    return pairs

# Пример использования:
numbers = [2, 4, 3, 5, 6, -2, 4, 7, 8, 9]
target = 7
print(find_pairs_with_sum(numbers, target))
# [(2, 5), (3, 4), (-2, 9)]
```

## Задача 10: Слияние двух словарей
**Задача:** Напишите функцию, которая объединяет два словаря. Если ключ присутствует в обоих словарях, значение из второго словаря должно заменить значение из первого.

**Диаграмма алгоритма:**
```
Начало → Получить dict1 и dict2 → Создать копию dict1 → 
Для каждого ключа-значения в dict2: обновить результат → 
Вернуть объединённый словарь
```

**Решение:**
```python
def merge_dictionaries(dict1, dict2):
    """
    Объединяет два словаря
    """
    # Создаём копию первого словаря
    merged = dict1.copy()
    
    # Обновляем значениями из второго словаря
    merged.update(dict2)
    
    return merged

# Пример использования:
dict_a = {"a": 1, "b": 2, "c": 3}
dict_b = {"c": 4, "d": 5, "e": 6}
result = merge_dictionaries(dict_a, dict_b)
print(result)  # {'a': 1, 'b': 2, 'c': 4, 'd': 5, 'e': 6}
```
