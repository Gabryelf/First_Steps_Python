# 🎯 **ПОШАГОВОЕ ОБЪЯСНЕНИЕ КОДА СОЦИАЛЬНОЙ СЕТИ**

## **📦 ШАГ 1: СОЗДАНИЕ СТРУКТУРЫ ДАННЫХ (ГРАФА)**

```python
graph = {
    'Аня': ['Боря', 'Ваня', 'Галя'],
    'Боря': ['Аня', 'Дима'],
    'Ваня': ['Аня'],
    'Галя': ['Аня', 'Егор'],
    'Дима': ['Боря'],
    'Егор': ['Галя']
}
```
> 🔵 **Объяснение:** Мы создаем словарь `graph`, который представляет собой социальную сеть. Каждый **ключ** (например, `'Аня'`) - это человек. Каждое **значение** (например, `['Боря', 'Ваня', 'Галя']`) - это список друзей этого человека.

**Визуализация нашей сети:**
```
    Аня
    /|\
   / | \
 Боря Ваня Галя
  |        |
 Дима     Егор
```

## **👥 ШАГ 2: ФУНКЦИЯ ДЛЯ ПОЛУЧЕНИЯ ВСЕХ ДРУЗЕЙ**

```python
def get_friends(name):
    """Получаем всех друзей человека"""
    return graph[name]
```
> 🟢 **Объяснение:** Это простая функция, которая принимает имя человека (`name`) и возвращает список его друзей. Когда мы вызываем `get_friends('Аня')`, Python делает:
> 1. Ищет ключ `'Аня'` в словаре `graph`
> 2. Возвращает значение по этому ключу: `['Боря', 'Ваня', 'Галя']`

**Пример использования:**
```python
print("Друзья Ани:", get_friends('Аня'))
# Вывод: Друзья Ани: ['Боря', 'Ваня', 'Галя']
```

## **🔍 ШАГ 3: ФУНКЦИЯ ДЛЯ ПОИСКА ОБЩИХ ДРУЗЕЙ**

```python
def common_friends(name1, name2):
    """Находим общих друзей двух людей"""
    friends1 = set(graph[name1])  # делаем множества
    friends2 = set(graph[name2])
```
> 🟡 **Объяснение:** 
> 1. `graph[name1]` - получаем список друзей первого человека
> 2. `set(graph[name1])` - преобразуем список в **множество (set)**
> 3. **Зачем множества?** Для быстрого поиска общих элементов

**Разница между списком и множеством:**
```python
# Список (list) - сохраняет порядок, могут быть дубликаты
friends_list = ['Боря', 'Ваня', 'Галя', 'Боря']  # Боря дважды!

# Множество (set) - не сохраняет порядок, только уникальные элементы  
friends_set = {'Боря', 'Ваня', 'Галя'}  # Боря только один раз
```

## **🎯 ШАГ 4: НАХОЖДЕНИЕ ПЕРЕСЕЧЕНИЯ МНОЖЕСТВ**

```python
    common = friends1 & friends2  # пересечение множеств
```
> 🔴 **Объяснение:** Оператор `&` (амперсанд) находит **пересечение** двух множеств - то есть элементы, которые есть в ОБОИХ множествах.

**Как это работает:**
```python
set1 = {'Боря', 'Ваня', 'Галя'}    # друзья Ани
set2 = {'Аня', 'Дима'}            # друзья Бори

result = set1 & set2
# result = set()  # пустое множество, потому что нет общих элементов
```

---

## **📊 ШАГ 5: ВЫВОД РЕЗУЛЬТАТОВ**

```python
    if common:
        print(f"Общие друзья {name1} и {name2}: {list(common)}")
    else:
        print(f"У {name1} и {name2} нет общих друзей")

    return common
```
> 🟣 **Объяснение:**
> 1. `if common:` - проверяем, не пустое ли множество. В Python пустое множество считается `False`
> 2. `list(common)` - преобразуем множество обратно в список для красивого вывода
> 3. `return common` - возвращаем результат (можно использовать дальше в программе)

## **🚀 ШАГ 6: ЗАПУСК ФУНКЦИЙ С ПРИМЕРАМИ**

```python
common_friends('Аня', 'Боря')
common_friends('Аня', 'Дима')
```

### **ПЕРВЫЙ ВЫЗОВ: `common_friends('Аня', 'Боря')`**

**Что происходит пошагово:**

1. **Получаем друзей Ани:**
   ```python
   friends1 = set(graph['Аня'])  # graph['Аня'] = ['Боря', 'Ваня', 'Галя']
   # friends1 = {'Боря', 'Ваня', 'Галя'}
   ```

2. **Получаем друзей Бори:**
   ```python
   friends2 = set(graph['Боря'])  # graph['Боря'] = ['Аня', 'Дима']
   # friends2 = {'Аня', 'Дима'}
   ```

3. **Находим пересечение:**
   ```python
   common = friends1 & friends2
   # {'Боря', 'Ваня', 'Галя'} & {'Аня', 'Дима'} = set()
   # Пустое множество - нет общих друзей!
   ```

4. **Вывод:**
   ```
   У Аня и Боря нет общих друзей
   ```

**💡 Интересно:** Хотя Аня и Боря дружат друг с другом, они не считаются "общими друзьями" сами с собой!

---

### **ВТОРОЙ ВЫЗОВ: `common_friends('Аня', 'Дима')`**

**Что происходит пошагово:**

1. **Получаем друзей Ани:**
   ```python
   friends1 = set(graph['Аня'])  # {'Боря', 'Ваня', 'Галя'}
   ```

2. **Получаем друзей Димы:**
   ```python
   friends2 = set(graph['Дима'])  # graph['Дима'] = ['Боря']
   # friends2 = {'Боря'}
   ```

3. **Находим пересечение:**
   ```python
   common = friends1 & friends2
   # {'Боря', 'Ваня', 'Галя'} & {'Боря'} = {'Боря'}
   ```

4. **Вывод:**
   ```
   Общие друзья Аня и Дима: ['Боря']
   ```

**✅ Правильно!** И Аня, и Дима дружат с Борей, поэтому Боря - их общий друг.

## **📚 КЛЮЧЕВЫЕ ПОНЯТИЯ, КОТОРЫЕ МЫ ИЗУЧИЛИ:**

| Концепция | Пример | Объяснение |
|-----------|--------|------------|
| **Словарь (dict)** | `graph = {'Аня': [...], ...}` | Хранит пары ключ-значение |
| **Список (list)** | `['Боря', 'Ваня', 'Галя']` | Упорядоченная коллекция |
| **Множество (set)** | `{'Боря', 'Ваня', 'Галя'}` | Коллекция уникальных элементов |
| **Оператор &** | `set1 & set2` | Пересечение множеств |
| **Функция** | `def common_friends():` | Блок кода, который можно повторно использовать |

## **🚀 ПОЛНЫЙ КОД С КОММЕНТАРИЯМИ:**

```python
# 1. СОЗДАЕМ СОЦИАЛЬНУЮ СЕТЬ КАК ГРАФ
#    Ключи - имена людей, значения - списки их друзей
graph = {
    'Аня': ['Боря', 'Ваня', 'Галя'],  # Аня дружит с Борей, Ваней и Галей
    'Боря': ['Аня', 'Дима'],          # Боря дружит с Аней и Димой
    'Ваня': ['Аня'],                  # Ваня дружит только с Аней
    'Галя': ['Аня', 'Егор'],          # Галя дружит с Аней и Егором
    'Дима': ['Боря'],                 # Дима дружит только с Борей
    'Егор': ['Галя']                  # Егор дружит только с Галей
}

# 2. ФУНКЦИЯ ДЛЯ ПОЛУЧЕНИЯ ДРУЗЕЙ ЧЕЛОВЕКА
def get_friends(name):
    """Получаем всех друзей человека"""
    return graph[name]  # Просто возвращаем список из словаря

# 3. ФУНКЦИЯ ДЛЯ ПОИСКА ОБЩИХ ДРУЗЕЙ
def common_friends(name1, name2):
    """Находим общих друзей двух людей"""
    # Преобразуем списки друзей в множества
    friends1 = set(graph[name1])  # Множество друзей первого человека
    friends2 = set(graph[name2])  # Множество друзей второго человека
    
    # Находим пересечение множеств (общие элементы)
    common = friends1 & friends2
    
    # Выводим результат
    if common:  # Если множество не пустое
        print(f"Общие друзья {name1} и {name2}: {list(common)}")
    else:       # Если множество пустое
        print(f"У {name1} и {name2} нет общих друзей")
    
    return common  # Возвращаем результат

# 4. ТЕСТИРУЕМ ФУНКЦИИ
print("=" * 50)
print("ТЕСТ 1: Аня и Боря")
common_friends('Аня', 'Боря')  # Должно быть пусто

print("\n" + "=" * 50)
print("ТЕСТ 2: Аня и Дима")
common_friends('Аня', 'Дима')  # Должен найти Борю

# print("\n" + "=" * 50)
# print("Друзья Ани:", get_friends('Аня'))
# print("Друзья Бори:", get_friends('Боря'))
```

Теперь вы полностью понимаете, как работает этот код! Каждая строка имеет свою важную роль в анализе социальной сети. 🎉
