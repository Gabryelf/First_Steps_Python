## **СТРОКА 9-11: ЗАГРУЗКА СТРАНИЦЫ**
```python
        # 1. Скачиваем страницу
        with urllib.request.urlopen(url) as response:
            html = response.read().decode('utf-8', errors='ignore')
```
**Построчно:**
1. `# 1. Скачиваем страницу` — комментарий. Начинается с `#`, Python игнорирует эти строки
2. `with urllib.request.urlopen(url) as response:` — открываем соединение с сайтом по адресу `url`
   - `with` — специальная конструкция, которая автоматически закроет соединение после использования
   - `urllib.request.urlopen(url)` — функция, которая идет на сайт и скачивает его
   - `as response` — результат работы функции сохраняем в переменную `response` ("ответ")
3. `html = response.read().decode('utf-8', errors='ignore')` — читаем и преобразуем данные
   - `response.read()` — читаем содержимое страницы (получаем байты, как цифровой поток)
   - `.decode('utf-8')` — преобразуем байты в читаемый текст. UTF-8 — стандартная кодировка для интернета
   - `errors='ignore'` — если встретятся непонятные символы, просто пропустить их
   - `html = ` — сохраняем результат в переменную `html`

## **СТРОКА 14-15: РЕГУЛЯРНОЕ ВЫРАЖЕНИЕ ДЛЯ H1**
```python
        # 2. Ищем заголовки <h1>
        h1_pattern = r'<h1[^>]*>(.*?)</h1>'
```
**Построчно:**
1. `# 2. Ищем заголовки <h1>` — комментарий
2. `h1_pattern = r'<h1[^>]*>(.*?)</h1>'` — создаем шаблон для поиска
   - `h1_pattern =` — создаем переменную с именем `h1_pattern` ("шаблон для h1")
   - `r'...'` — `r` означает "raw string" (сырая строка). Нужно для регулярных выражений
   - `<h1[^>]*>` — ищем начало тега `<h1`
     - `<h1` — буквально ищет `<h1`
     - `[^>]*` — `[^>]` означает "любой символ, кроме `>`". `*` означает "ноль или больше раз"
     - `>` — закрывающая угловая скобка
   - `(.*?)` — захватываем содержимое тега
     - `(` и `)` — создают "группу захвата". То, что внутри, мы сможем извлечь отдельно
     - `.` — любой символ
     - `*?` — "ноль или больше раз, но как можно меньше" (нежадный режим)
   - `</h1>` — буквально ищет закрывающий тег

**Пример:**
Для HTML `<h1 class="main">Привет мир</h1>` найдет: `Привет мир`

## **СТРОКА 16: ПОИСК ПО ШАБЛОНУ**
```python
        h1_matches = re.findall(h1_pattern, html, re.DOTALL | re.IGNORECASE)
```
**Что происходит:**
- `h1_matches =` — результат поиска сохраняем в переменную `h1_matches` ("совпадения h1")
- `re.findall()` — функция из модуля `re`, которая находит ВСЕ совпадения с шаблоном
- `(h1_pattern, html, re.DOTALL | re.IGNORECASE)` — параметры функции:
  1. `h1_pattern` — шаблон для поиска (что ищем)
  2. `html` — текст, в котором ищем (где ищем)
  3. `re.DOTALL | re.IGNORECASE` — флаги (настройки поиска)
     - `re.DOTALL` — точка `.` теперь включает символы переноса строки
     - `|` — логическое "ИЛИ" (применяем оба флага)
     - `re.IGNORECASE` — игнорировать регистр (находит `<H1>`, `<h1>`, `<H1>`)

## **СТРОКА 21: УДАЛЕНИЕ HTML-ТЕГОВ**
```python
            return re.sub(r'<[^>]+>', '', text).strip()
```
**Построчно:**
- `return` — возвращаем результат работы функции
- `re.sub()` — функция замены в тексте
- `(r'<[^>]+>', '', text)` — параметры:
  1. `r'<[^>]+>'` — шаблон для поиска (что заменять)
     - `<` — буквально символ `<`
     - `[^>]+` — один или больше (`+`) любых символов, кроме `>`
     - `>` — буквально символ `>`
  2. `''` — на что заменять (пустая строка, то есть удалить)
  3. `text` — текст, в котором производим замену
- `.strip()` — удаляет пробелы в начале и конце строки

**Пример:**
`"  <b>Жирный</b> текст  "` → `"Жирный текст"`

## **СТРОКА 25-28: ВЫВОД НАЙДЕННЫХ ЗАГОЛОВКОВ**
```python
        for i, match in enumerate(h1_matches[:5], 1):
            clean_text = clean_html(match)[:100]
            if clean_text:
                print(f"  {i}. {clean_text}")
```
**Построчно:**
1. `for i, match in enumerate(h1_matches[:5], 1):` — цикл по найденным заголовкам
   - `for` — начало цикла
   - `i, match in` — распаковка: `i` будет номером, `match` — значением
   - `enumerate(h1_matches[:5], 1)` — функция, которая нумерует элементы
     - `h1_matches[:5]` — берем только первые 5 элементов из списка
     - `[:5]` — срез списка: от начала до 5-го элемента (не включая)
     - `, 1` — начинать нумерацию с 1 (по умолчанию с 0)
   - `:` — начало тела цикла

2. `clean_text = clean_html(match)[:100]` — очищаем текст и обрезаем
   - `clean_html(match)` — вызываем нашу функцию очистки для текущего совпадения
   - `[:100]` — берем только первые 100 символов (чтобы не выводить слишком длинный текст)

3. `if clean_text:` — проверка: если текст не пустой
   - В Python пустая строка `""` считается `False`

4. `print(f"  {i}. {clean_text}")` — вывод результата
   - `"  {i}. {clean_text}"` — f-строка с подстановкой переменных
   - `{i}` — подставляется номер
   - `{clean_text}` — подставляется очищенный текст
   - `  ` — два пробела в начале для отступа

- `link_pattern = r'href="(https?://[^"]+)"'` — создаем шаблон для поиска ссылок

- `[^"]+` — один или больше любых символов, кроме `"`
- `)"` — закрывающая кавычка

## 🌳 **ПРИЧЕМ ТУТ ДЕРЕВЬЯ?**

HTML страница — это **дерево тегов**:

```
html (корень)
├── head
│   ├── title
│   └── meta
└── body (узел)
    ├── h1 (лист с текстом)
    ├── div (узел)
    │   ├── p (лист)
    │   └── a (лист со ссылкой)
    └── footer (лист)
```

**Наш парсер** ищет определенные части этого дерева:
- Ищет все элементы `<h1>` (заголовки первого уровня)
- Ищет все элементы `<a>` с атрибутом `href` (ссылки)

**Если бы мы делали полноценный парсер дерева:**
```python
# Вместо поиска regex мы бы строили дерево:
html_tree = {
    'tag': 'html',
    'children': [
        {
            'tag': 'body',
            'children': [
                {'tag': 'h1', 'text': 'Заголовок', 'children': []},
                {'tag': 'a', 'href': 'https://...', 'children': []}
            ]
        }
    ]
}
```
