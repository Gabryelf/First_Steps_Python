
# 📝 Заметки — учим Python на практике

Простой проект для изучения Python с нуля. Сделаем программу для заметок в трёх версиях: от самой простой до программы с графическим окном.

## 🎯 Что изучаем

| Версия | Что нового |
|--------|------------|
| **Версия 1** | Переменные, списки, словари, функции, циклы |
| **Версия 2** | Классы, объекты, разделение кода |
| **Версия 3** | Графический интерфейс (tkinter) |

## 🚀 Запуск

```bash
# Самая простая версия (для начала)
python 01_simple_notes.py

# Версия с классами
python 02_notes_oop.py

# Версия с графикой (нужен tkinter)
python 03_notes_gui.py
```

## 📚 Шпаргалка для новичков

**Список** — упорядоченная коллекция
```python
notes = []                    # пустой список
notes.append("привет")        # добавить
notes[0]                      # взять первый
len(notes)                    # сколько элементов
```

**Словарь** — хранит пары ключ→значение
```python
note = {
    'id': 1,
    'title': 'Заголовок'
}
note['title']                 # получить значение
```

**Функция** — кусок кода с именем
```python
def say_hello(name):
    print(f"Привет, {name}!")
```

**Класс** — чертёж для объектов
```python
class Student:
    def __init__(self, name):
        self.name = name
    
    def introduce(self):
        print(f"Я {self.name}")
```
