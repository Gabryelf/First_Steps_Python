

## **1. Создание главного окна**
```python
root = tk.Tk()
```
- Создается экземпляр главного окна приложения
- `Tk()` — это основной класс tkinter, который инициализирует графическое окно

```python
root.title("МОИ ЗАМЕТКИ")
```
- Устанавливает заголовок окна — "МОИ ЗАМЕТКИ"

```python
root.geometry("600x450")
```
- Задает размеры окна: **600 пикселей ширина × 450 пикселей высота**

---

## **2. Создание списка заметок**
```python
listbox = tk.Listbox(root, height=15, font=("Arial", 10))
```
- Создает виджет `Listbox` (список) внутри главного окна
- `height=15` — отображает 15 строк одновременно
- `font=("Arial", 10)` — устанавливает шрифт Arial размером 10

```python
listbox.pack(fill=tk.BOTH, expand=True, padx=10, pady=5)
```
- Размещает список в окне с помощью менеджера геометрии `pack()`
- `fill=tk.BOTH` — растягивает список в обе стороны (горизонтально и вертикально)
- `expand=True` — позволяет списку расширяться при изменении размера окна
- `padx=10, pady=5` — добавляет внешние отступы: 10 пикселей по горизонтали, 5 по вертикали

---

## **3. Создание фрейма для кнопок**
```python
button_frame = tk.Frame(root)
```
- Создает контейнер `Frame` для группировки кнопок

```python
button_frame.pack(pady=5)
```
- Размещает фрейм под списком
- `pady=5` — добавляет вертикальный отступ в 5 пикселей

---

## **4. Создание кнопок управления**

Все кнопки размещаются в одном фрейме горизонтально:

```python
tk.Button(button_frame, text="1. Показать все", command=show_all_notes, width=15).pack(side=tk.LEFT, padx=2)
```
- **Показать все** — вызывает функцию `show_all_notes()`
- `side=tk.LEFT` — выравнивание кнопки по левому краю
- `width=15` — ширина кнопки в символах
- `padx=2` — горизонтальный отступ между кнопками

```python
tk.Button(button_frame, text="2. Добавить", command=add_note, width=15).pack(side=tk.LEFT, padx=2)
```
- **Добавить** — вызывает функцию `add_note()` для создания новой заметки

```python
tk.Button(button_frame, text="3. Посмотреть", command=view_note, width=15).pack(side=tk.LEFT, padx=2)
```
- **Посмотреть** — вызывает функцию `view_note()` для просмотра выбранной заметки

```python
tk.Button(button_frame, text="4. Удалить", command=delete_note, width=15).pack(side=tk.LEFT, padx=2)
```
- **Удалить** — вызывает функцию `delete_note()` для удаления выбранной заметки

```python
tk.Button(button_frame, text="0. Выход", command=root.quit, width=15).pack(side=tk.LEFT, padx=2)
```
- **Выход** — вызывает `root.quit()` для завершения программы
