# 📦 ЗАДАНИЕ 1 — Раздели и властвуй (3 балла)

Сейчас все классы находятся в `game_objects.py`.
Это удобно… пока проект маленький 😏

### 🛠 Нужно:

Разделить классы по отдельным файлам:

```
game_objects/
│
├── base_object.py      → GameObject
├── tank.py             → Tank
├── player.py           → Player
├── enemy.py            → Enemy
├── bullet.py           → Bullet
```

📌 Обновить импорты в проекте.
📌 Проверить, чтобы игра запускалась без ошибок.

💡 Бонус-совет: создай `__init__.py` в папке `game_objects`.

# ❤️ ЗАДАНИЕ 2 — Система жизней и аптечки (3 балла)

Сейчас игрок умирает с одного попадания. Это слишком хардкор 😅

### 🛠 Нужно:

1. Добавить игроку **жизни (например 3)**.
2. Пуля врага уменьшает жизни на 1.
3. Если жизни = 0 → GAME OVER.
4. Добавить **аптечки**, которые:

   * случайно появляются на поле
   * увеличивают жизнь игрока на 1
   * исчезают после подбора

📌 Аптечки не должны появляться внутри стен.
📌 Максимальное количество жизней можно ограничить (например 5).

💊 Сделай отдельный класс `HealthPack`.

# 🔥 ЗАДАНИЕ 3 — Новый тип врага (3 балла)

Добавь **продвинутого врага** 😈

### Его особенности:

* Другой цвет
* 2 жизни
* Стреляет чаще
* Возможно, двигается быстрее (по желанию)

📌 При попадании первая пуля снимает 1 жизнь, а не убивает.
📌 Можно создать класс `StrongEnemy`, наследник `Enemy`.

# 💣 ЗАДАНИЕ 4 — Ловушки (3 балла)

Игрок теперь может ставить ловушки 😎

### 🛠 Нужно:

* По нажатию кнопки (например `E`) ставится ловушка.
* Ловушка:

  * не наносит урон игроку
  * наносит 1 урон врагу
  * исчезает после срабатывания

📌 Добавить ограничение на количество ловушек (например 3 одновременно).
📌 Сделать отдельный класс `Trap`.
