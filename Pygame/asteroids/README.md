## 🚀 Задание 6. Добавь счёт за хорошие астероиды на экран
**Файл:** `Game.py`  
Сейчас счёт отображается только внизу. Сделай так, чтобы при сборе хорошего астероида на месте его исчезновения появлялась цифра "+1", которая плавно поднимается вверх и исчезает.

🔍 **Подсказка:**  
Это сложное задание! Потребуется создать новый класс `ScorePopup`:
```python
class ScorePopup(RenderableObject):
    def __init__(self, x, y):
        self.x = x
        self.y = y
        self.text = "+1"
        self.life = 30  # сколько кадров жить
        self.font = pygame.font.Font(None, 24)
    
    def update(self):
        self.y -= 1  # поднимается вверх
        self.life -= 1
    
    def draw(self, surface):
        if self.life > 0:
            text = self.font.render(self.text, True, (255, 255, 255))
            surface.blit(text, (self.x, self.y))
```

В `Game` добавь список `popups`, при сборе хорошего астероида создавай `ScorePopup` и добавляй в список.  
В `game_logic()` обновляй все popups и удаляй те, у которых `life <= 0`.

## 🚀 Задание 9. Добавь эффект взрыва при смерти
**Файл:** `Game.py` и `Explosion.py` (новый файл)  
Когда у игрока заканчиваются жизни, вместо простого закрытия игры покажи анимацию взрыва корабля.

🔍 **Подсказка:**  
Создай класс `Explosion`:
```python
class Explosion(RenderableObject):
    def __init__(self, x, y):
        self.x = x
        self.y = y
        self.frames = []  # список картинок для анимации
        self.current_frame = 0
        self.frame_count = 0
    
    def update(self):
        self.frame_count += 1
        if self.frame_count % 5 == 0:  # меняем кадр каждые 5 кадров
            self.current_frame += 1
    
    def draw(self, surface):
        if self.current_frame < len(self.frames):
            surface.blit(self.frames[self.current_frame], (self.x, self.y))
```

В `Game` при смерти игрока:
- Останови спавн астероидов.
- Создай объект взрыва на месте корабля.
- Обновляй его в `game_logic()`.
- Когда анимация закончится — закрывай игру.
