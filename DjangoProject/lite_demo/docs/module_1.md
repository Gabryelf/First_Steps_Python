# Руководство по созданию базового проекта на Django

## Шаг 1: Установка Django

**Комментарий:** Django устанавливается через пакетный менеджер Python (pip). Убедитесь, что у вас установлен Python версии 3.8 или выше.

```bash
pip install django
```

---

## Шаг 2: Создание проекта

**Комментарий:** Команда `django-admin startproject` создает базовую структуру проекта Django. `mysite` - это имя вашего проекта, его можно изменить на любое другое.

```bash
django-admin startproject mysite
cd mysite
```

---

## Шаг 3: Создание приложения

**Комментарий:** В Django проект состоит из одного или нескольких приложений. Приложение - это модуль, который реализует определенную функциональность. Создадим приложение с именем `main`.

```bash
python manage.py startapp main
```

---

## Шаг 4: Настройка проекта (settings.py)

**Комментарий:** Файл `settings.py` содержит все настройки проекта. Здесь мы добавим наше приложение в список установленных приложений и настроим базовые маршруты.

**Файл: mysite/settings.py**
```python
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'main',
]
```

---

## Шаг 5: Создание представления (view)

**Комментарий:** Представление (view) - это функция Python, которая принимает HTTP-запрос и возвращает HTTP-ответ. Здесь мы создаем простейшее представление, которое возвращает текстовый ответ.

**Файл: main/views.py**
```python
from django.http import HttpResponse

def home(request):
    return HttpResponse("Добро пожаловать в наш сайт на Django!")
```

---

## Шаг 6: Настройка URL-маршрутов приложения

**Комментарий:** Каждое приложение имеет свой файл `urls.py`, который определяет, какие URL-адреса будут обрабатываться этим приложением и каким представлениям они соответствуют.

**Файл: main/urls.py**
```python
from django.urls import path
from . import views

urlpatterns = [
    path('', views.home, name='home'),
]
```

---

## Шаг 7: Настройка URL-маршрутов проекта

**Комментарий:** Главный файл `urls.py` проекта связывает URL-адресы с приложениями. Когда пользователь заходит на сайт, Django ищет совпадение URL в этом файле.

**Файл: mysite/urls.py**
```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('main.urls')),
]
```

---

## Шаг 8: Запуск сервера разработки

**Комментарий:** Django включает встроенный сервер для разработки. Он автоматически перезагружается при изменении кода. Сервер запускается на порту 8000 по умолчанию.

```bash
python manage.py runserver
```

**После запуска откройте в браузере:** http://127.0.0.1:8000

---

## Шаг 9: Создание шаблона (необязательно)

**Комментарий:** Шаблоны позволяют отделить HTML-разметку от логики Python. Создадим простой HTML-шаблон для нашего представления.

**Сначала изменим представление:**
**Файл: main/views.py**
```python
from django.shortcuts import render

def home(request):
    return render(request, 'main/home.html')
```

**Затем создадим структуру папок и шаблон:**
```bash
mkdir -p main/templates/main
```

**Файл: main/templates/main/home.html**
```html
<!DOCTYPE html>
<html>
<head>
    <title>Мой сайт на Django</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Это мой первый сайт на Django</p>
</body>
</html>
```

---

## Шаг 10: Миграции базы данных

**Комментарий:** Django использует систему миграций для управления структурой базы данных. Даже в самом простом проекте Django использует базу данных для хранения информации о сессиях, пользователях и т.д.

```bash
python manage.py migrate
```

## Что мы сделали:

1. **Установили Django** - фреймворк для веб-разработки на Python
2. **Создали проект** - каркас всего веб-приложения
3. **Создали приложение** - модуль с конкретной функциональностью
4. **Настроили проект** - добавили приложение в настройки
5. **Создали представление** - логику обработки запросов
6. **Настроили маршруты** - связь между URL и представлениями
7. **Запустили сервер** - для тестирования приложения
8. **Создали шаблон** (опционально) - для отображения HTML
9. **Выполнили миграции** - подготовили базу данных

## Проверка работоспособности:

1. Запустите сервер: `python manage.py runserver`
2. Откройте браузер и перейдите по адресу: http://127.0.0.1:8000
3. Вы должны увидеть сообщение "Добро пожаловать в наш сайт на Django!" или содержимое HTML-шаблона

Это минимальный рабочий проект Django, который демонстрирует основные концепции фреймворка: проекты, приложения, представления, URL-маршрутизацию и шаблоны.
