# Модуль 2: Расширяем функционал Django-проекта

В этом модуле мы добавим к нашему базовому проекту несколько важных функций: модели для работы с базой данных, формы для взаимодействия с пользователем и административную панель Django.

---

## Шаг 1: Создание модели данных

**Комментарий:** Модели в Django - это Python-классы, которые описывают структуру таблиц в базе данных. Каждый атрибут класса становится полем в таблице. Django автоматически создает SQL-запросы для работы с этими таблицами.

**Файл: main/models.py**
```python
from django.db import models

class Article(models.Model):
    title = models.CharField(max_length=200)
    content = models.TextField()
    created_at = models.DateTimeField(auto_now_add=True)
    is_published = models.BooleanField(default=True)

    def __str__(self):
        return self.title
```

**Что мы сделали:**
- Создали модель `Article` (Статья) с четырьмя полями
- `CharField` - для короткого текста (заголовок)
- `TextField` - для длинного текста (содержание)
- `DateTimeField` - с автоматическим заполнением даты создания
- `BooleanField` - для флага публикации
- Метод `__str__` определяет, как объект будет отображаться в админке и оболочке

---

## Шаг 2: Регистрация модели в административной панели

**Комментарий:** Django предоставляет готовую административную панель для управления данными. Чтобы наша модель отображалась в админке, нужно зарегистрировать ее в файле `admin.py`.

**Файл: main/admin.py**
```python
from django.contrib import admin
from .models import Article

admin.site.register(Article)
```

---

## Шаг 3: Создание и применение миграций

**Комментарий:** Миграции - это способ Django отслеживать изменения в моделях и применять их к базе данных. После создания модели нужно создать миграцию и применить ее.

```bash
# Создаем миграцию на основе изменений в моделях
python manage.py makemigrations main

# Применяем миграцию к базе данных
python manage.py migrate
```

**Что произошло:**
- `makemigrations` создает файлы миграций с SQL-командами
- `migrate` выполняет эти команды в базе данных
- Проверьте созданные таблицы в `db.sqlite3` (файл базы данных появится в проекте)

---

## Шаг 4: Создание суперпользователя

**Комментарий:** Чтобы получить доступ к административной панели, нужно создать учетную запись с правами администратора. Суперпользователь имеет полный доступ ко всем функциям Django.

```bash
python manage.py createsuperuser
```

**Введите:**
- Имя пользователя (например, `admin`)
- Email (необязательно)
- Пароль (дважды, пароль не будет отображаться при вводе)

## Шаг 5: Создание формы для добавления статей

**Комментарий:** Формы Django упрощают создание HTML-форм, валидацию данных и сохранение в базу данных. Мы создадим простую форму на основе нашей модели.

**Файл: main/forms.py**
```python
from django import forms
from .models import Article

class ArticleForm(forms.ModelForm):
    class Meta:
        model = Article
        fields = ['title', 'content', 'is_published']
```

**Что мы сделали:**
- Создали класс формы, наследующийся от `ModelForm`
- Указали, какая модель будет использоваться
- Определили, какие поля модели будут в форме

---

## Шаг 6: Обновление представления для работы с формой

**Комментарий:** Теперь нужно изменить наше представление, чтобы оно могло обрабатывать форму. Мы добавим логику для отображения формы и сохранения данных при отправке формы.

**Файл: main/views.py**
```python
from django.shortcuts import render, redirect
from .forms import ArticleForm
from .models import Article

def home(request):
    # Получаем все статьи из базы данных
    articles = Article.objects.all()
    
    # Если форма была отправлена (POST-запрос)
    if request.method == 'POST':
        form = ArticleForm(request.POST)
        if form.is_valid():
            form.save()  # Сохраняем статью в базу данных
            return redirect('home')  # Перенаправляем на главную
    else:
        form = ArticleForm()  # Создаем пустую форму для GET-запроса
    
    # Передаем статьи и форму в шаблон
    return render(request, 'main/home.html', {
        'articles': articles,
        'form': form
    })
```

**Что мы добавили:**
- Логику обработки GET и POST запросов
- Сохранение данных формы в базу данных
- Перенаправление после успешного сохранения
- Получение всех статей из базы для отображения

## Шаг 7: Обновление шаблона

**Комментарий:** Теперь обновим наш HTML-шаблон, чтобы отображать форму для добавления статей и список существующих статей.

**Файл: main/templates/main/home.html**
```html
<!DOCTYPE html>
<html>
<head>
    <title>Сайт со статьями на Django</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="container mt-4">
    <h1 class="mb-4">Мой блог на Django</h1>

    <div class="card mb-4">
        <div class="card-header">
            <h2 class="h5 mb-0">Добавить новую статью</h2>
        </div>
        <div class="card-body">
            <form method="post">
                {% csrf_token %}

                {% if form.errors %}
                    <div class="alert alert-danger mb-3">
                        Пожалуйста, исправьте ошибки ниже.
                    </div>
                {% endif %}

                {% for field in form %}
                    <div class="mb-3">
                        <label class="form-label">{{ field.label }}:</label>
                        {{ field }}
                        {% if field.errors %}

                                {{ field.errors }}

        </div>
```

**Что мы добавили в шаблон:**
- Форму с полями для ввода данных
- Автоматическую генерацию HTML-полей из формы Django
- Защиту от CSRF-атак (обязательно для POST-форм в Django)
- Отображение списка статей из базы данных
- Фильтры для форматирования даты и обрезки текста
- Ссылку на административную панель
